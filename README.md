Two-line explanation for the [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty on [make.fun](https://make.fun). Line 1 explains a toaster to a 10-year-old in a single vivid sentence built on an analogy; line 2 says in one sentence why that analogy works — what it maps and what it leaves out.

## Run

```sh
python3 main.py
```

This writes the two lines to `/output/entry.txt`.

## Entry

> A toaster is a sunbathing bed for bread: two glowing red bars tan each side until it pops up brown and crisp.
>
> It maps the heat on both sides and the timed pop-up, but leaves out the wires and thermostat that actually do the work.

The program validates the output before writing it: exactly 2 lines, 1–400 characters total, each line a single sentence, valid UTF-8.
